accessibility rules in DESIGN-SYSTEM.md, and make them machine-checkable so every later UI phase is
linted against them.

```gherkin

    When the c0 lint runs

    Given the recorded violation floor
    When the lint runs on a later commit
    Then a count above the floor fails
```
