# F8 — Sovereignty Shield (live air-gap indicator)

## Goal

A live top-bar chip watching ACTUAL socket state (psutil/OS-level, not self-reporting): all
loopback → "🛡️ 100% Local"; a configured remote fallback active → "🌐 Hybrid — cloud fallback
active"; click → real-time egress audit (which runs sent what token counts to which endpoint, fed
by F5/G0 remote attribution). The zero-phone-home NFR becomes something the user watches being true.
