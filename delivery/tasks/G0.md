# G0 — Unified run-event stream (lineage native to telemetry)

## Goal
One append-only events.jsonl per run, written only by the pypes orchestrator: run_started header freezes
the DAG; node/artifact events carry telemetry; lineage is a fold over artifact events. OpenLineage/Marquez
becomes an optional tail-adapter — never inline HTTP (the RAG-wedge lesson).

## Context pointers
- Plan section 4, G0 card (exact event types/fields); orchestrator already topo-sorts (runtime/benny/pypes/orchestrator.py:180,504)
- Wedge lesson: header comment in runtime/benny/governance/lineage.py — preserve BENNY_LINEAGE_ENABLED semantics
- Storage: PRIME_SILO_HOME/runs/<run_id>/events.jsonl; legacy AER/Runs readers keep working (protocol rule 6)
- Telemetry fields: tokens_in/out, duration_ms, model, endpoint (feeds F5 meter + energy accounting)

## TDD plan
1. Schema tests: every event type validates; unknown node_id (not in frozen header) rejected — red.
2. Implement events.py single emitter; wire orchestrator step boundaries — green.
3. Fold test: example run -> fold reproduces current `benny runs inspect` lineage.
4. Hot-path tests: write failure degrades (never fails the step); Marquez down + lineage enabled -> step wall time within 5%.

## Acceptance
```gherkin
Feature: one event stream is progress, telemetry, and lineage
  Scenario: the DAG is frozen at run start
    Given a run_started header listing nodes a, b, c
    When an event referencing node d is validated
    Then it is rejected

  Scenario: lineage is a fold, not a second system
    Given a completed example-manifest run's events.jsonl
    When artifact events are folded
    Then the lineage equals what benny runs inspect reports today

  Scenario: event emission never blocks execution
    Given an events file that cannot be written
    When a step executes
    Then the step completes and the failure is logged, not raised

  Scenario: dead Marquez cannot wedge the run
    Given BENNY_LINEAGE_ENABLED=1 and no Marquez listening
    When the example manifest runs
    Then per-step wall time is within 5% of the lineage-disabled baseline
```
