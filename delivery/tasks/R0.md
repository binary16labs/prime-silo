# R0 — Target-app ingestion profile + baseline

## Goal
Generalize existing ingestion + `benny enrich` from "prime-silo analyzing itself" to any
`target_repo` parameter. Fixed-shape DAG: inventory → static_extract (AST symbols, dep edges,
entry points, routes, DB schemas, config, external calls — all deterministic) → doc_ingest →
graph_build (namespaced per target) → narrate (A1-windowed, every claim cites node ids) →
coverage_report (honest gaps).

## Context pointers
- Plan §8 R0 card (PLAN-local-power-unified-ui.md:412-416); anti-hallucination contract at §8 head: uncited claims fail by script
- Baseline fixture: a small known app from binary16 (e.g. chattabot or audio-converter-ui) with hand-verified inventory recorded in the gate
- Vision pipeline VIS-001 handles docs' figures/diagrams

## TDD plan
1. Red: fixture recall — graph must contain every known endpoint/entry point from the hand-verified list.
2. Red: coverage report ≥90% files inventoried with gaps listed.
3. Generalize extractors — green. 4. Citation resolution over all narration.

## Acceptance
```gherkin
Feature: any repo becomes a grounded graph
  Scenario: nothing known is missed
    Given the fixture app's hand-verified endpoint list
    When ingestion runs
    Then every listed endpoint and entry point exists in the graph

  Scenario: coverage is honest
    Then the coverage report shows at least 90 percent of files inventoried and lists every gap

  Scenario: narration is grounded
    Then every narration claim cites node ids that resolve in the graph
```
