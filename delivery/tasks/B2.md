# B2 — Agent surfaces: CLI + MCP over one ledger

## Goal
`benny coord ls|claim|progress|done|note` CLI plus MCP tools (`coord_list`, `coord_claim`,
`coord_report`, `coord_note`) in the prime-silo-nexus server — thin clients of the B1 API when the
server is up, with direct-file fallback (same B0 validator lib) when it isn't. One surface, four
agents (Claude, Antigravity, opencode, Benny).

## Context pointers
- Plan §3 B2 card (PLAN-local-power-unified-ui.md:218-221)
- Build registry-shaped from the start (name + params schema + handler) so G2 migration is a move, not a rewrite
- Offline-still-works is a hard requirement (direct-file mode uses server/coordination/lib/ledger.mjs semantics)
