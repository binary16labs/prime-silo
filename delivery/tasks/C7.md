# C7 — Cognitive profiles (Focus / Reading / Zen, one click)

## Goal
Three presets in the shell top bar + Setup, built entirely from C0 tokens/settings (no parallel
style system): ⚡ Focus (ADHD: amplified primary CTA, collapsed secondary panels, silenced
non-essential notifications, prominent step indicator), 📖 Reading (Dyslexia: high-legibility
stack, line-height 1.8, ≤65ch, reading ruler), 🌙 Zen (warm muted contrast, zero micro-animations,
log tails as plain-language bullets).
