# L9 — Privacy-honoring history + keep-both-and-flag conflict

## Goal
At projection, the leak-gate + quarantine/teleport filter applies so teleported sids never enter any
projection at any point in bi-temporal time; privacy deletions are tombstone events (moved, journalled,
reversible — never hard-erased); and semantic conflicts are kept-both-and-flagged — two events
contradicting at the same valid-time are BOTH projected with a conflict marker plus a conflict_flagged
review event, never auto-picked. R4, R6, R31; steer 9.

## TDD plan

## Acceptance (BDD — every Scenario must map to an automated test)
```gherkin
Feature: history honors privacy and never silently picks a winner
  Scenario: a teleported sid stays excluded across all time
    Given a sid teleported to quarantine
    When projections are queried at any valid-time or transaction-time

  Scenario: a privacy deletion is reversible, not erased
    Given a record requiring privacy deletion
    When it is removed
    Then it is tombstoned and quarantined (journalled, restorable), not hard-erased
  Scenario: contradictory facts are kept and flagged
    Given two events asserting contradictory facts at the same valid_time
    When the projection is built
    Then both are present with a conflict marker and a conflict_flagged review event is emitted
    And neither is auto-selected as the winner
```
