# M2-3 — Sealed exports (immutable, lineage-complete, ontology-transparent)

## Goal
Export any Studio/R artifact as a sealed document: (1) immutable — content-addressed hash tree,
signed with the per-install key, verifiable offline by a standalone verifier tool shipped with the
product; (2) lineage-complete — embeds the G0 lineage fold (runs, nodes, models, sources, hashes);
(3) ontology-transparent — embedded ontology manifest resolving every concept to its graph node +
a completeness attestation (included/excluded sources, coverage, honest gaps); (4) transparent
method — model ids, capability profiles, judge verdicts, prompt hashes. C2PA credentials in
rendered forms.
