# L16 — Version the observability surface (out of scratch/)

## Goal

The dashboard lives under `scratch/`, which is on the repo's never-commit list, so the observability
surface a regulator would be shown is an unversioned local artifact: it cannot be rebuilt from the
repo and no gate protects it from drift. **This is a code/state separation, not a flat move** —
4,607 lines of code across 17 files must become versioned, while 3.8 MB of generated state in the
same directory (`dashboard.json`, `openlineage.json`, `plan.json`, `togaf_epic_preview.html`) must
stay out of git and keep being generated. Independent of B4/B5/L15.

## Context pointers

- Review §2 — `scratch/` is never-commit (`.gitignore:66`); measured 2026-08-03, see LOG
- The dashboard is already ledger-sourced and deterministic; the code moves verbatim, unrewritten
- `dash.sh` → :8788; the pages compose existing libs

## Budget accounting (amended)

`budget: 400` counts **authored** lines only: path rewires, the state-dir split, the gate, tests.
The ~4,607 relocated lines are **exempt because they must be byte-identical** — a relocation is not
a review burden, and the exemption is only safe because the gate turns it into a checkable property.
If a relocated file differs from its `scratch/` original by one byte, it is no longer a relocation
and the exemption does not apply to it.

## TDD plan

1. Red: the gate fails while any dashboard asset resolves from `scratch/`.
2. Red: the gate fails if any relocated file differs from its original (byte-identity check).
3. Red: the gate fails if generated state is staged for commit.
4. Red: the dashboard builds from a clean checkout with no reads outside the repo.
5. Implement the move + state split + path updates. 6. Green; the old entry point is either kept
   working or removed deliberately, never left half-wired.
