# L16 — Version the observability surface (out of scratch/)

## Goal

The dashboard lives under `scratch/`, which is on the repo's never-commit list. The
observability surface a regulator would be shown is therefore an unversioned local artifact that cannot
be rebuilt from the repo and that no gate protects from drift. Move it to a versioned path with a gate.
Independent of B4/B5/L15 — do this first if the surface is ever shown to anyone.

## Context pointers

- Review §2 — `scratch/` is never-commit per the delivery skill's trap list
- The dashboard is already ledger-sourced and deterministic; this is relocation, not a rewrite
- `dash.sh` → :8788; the pages compose existing libs

## TDD plan

2. Red: the dashboard builds from a clean checkout with no reads outside the repo.
