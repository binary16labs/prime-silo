# G1 — DAG-aware terminal tracker (evolve BennyTUI)

## Goal
Add a DAG pane to the existing BennyTUI: nodes in topological waves, colored/glyphed by state,
current node's progress + log-tail beneath, artifacts as produced — driven ONLY by tailing the G0
stream (Contract 1: consumers never query the orchestrator). `benny runs watch <run_id>` attaches
to live or finished runs.

## Context pointers
- Plan §4 G1 card (PLAN-local-power-unified-ui.md:277-280); do NOT write a new TUI — evolve runtime/benny/agentamp/tui.py (BennyTUI, AAMP-001 Phase 4)
- Keep: skinnable palette, 80x24 floor with run_line_mode fallback, <300 ms first-frame NFR (§1.6 performance budget)
- Render node_heartbeat as liveness (prefill|generating|assembling) — "no output yet" ≠ "not working"
