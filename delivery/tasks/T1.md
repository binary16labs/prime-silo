# T1 — Clone the Benny home to the trainer (Windows→Windows)

## Goal
Make the trainer self-contained: carry a full clone of `PRIME_SILO_HOME` (code + RAG stores +
LONGVIEW cards/KG + Benny runtime) to the T480 so data-building, training, and RAG-grounded serving
all run locally — no hard LAN dependency during a run. Same-OS, so no store format conversion.

## Context pointers (never inline content)
- Design plan: `~/.claude/plans/mellow-tinkering-swan.md` — "Transfer strategy", "Phase 0.5"
- Home resolver (Node + Python) + `/api/home` provenance — see memory `prime_silo_home_unification_ui_status_plan` and root HOME-DIRECTORY.md
- Stores in the home: S16 RocksDB+USearch, memo-ray data, LONGVIEW cards/KG (Neo4j/Chroma per config)
- Risk: absolute-path assumptions baked into the home (drive letter / user dir) — not binary portability

## TDD plan
1. `scripts/gates/t1.mjs` red: asserts the trainer's `PRIME_SILO_HOME` resolves, and a known key
   reads back from each store (S16 doc+vector, one memo-ray session, LONGVIEW cards). Fails with a
   named per-store reason when a store won't open.
2. Snapshot on desktop (record source commit/timestamp), transfer, set `PRIME_SILO_HOME` on trainer.
3. Boot Benny against the clone; re-run gate green.

## Acceptance (BDD)
```gherkin
Feature: the trainer runs fully from a local clone of the Benny home
  Scenario: the home resolver points at the clone
    Given PRIME_SILO_HOME set to the transferred clone on the T480
    When the Node and Python home resolvers run
    Then both resolve to the clone with no unresolved absolute-path warnings

  Scenario: every store reads locally
    Given the cloned home on the trainer
    When a known key is read from S16, memo-ray, and the LONGVIEW cards store
    Then each returns the expected record without a network call to the desktop

  Scenario: provenance is recorded
    Given the clone was taken from the desktop
    Then docs/train/T1-clone-provenance.md records the source commit/timestamp and store checksums
```

## Out of scope
Training (T3), dataset building (T2). No edits to the canonical desktop home — clone is read-derived.

## Handoff
Verifier re-runs `node scripts/gates/t1.mjs` on the T480. Provenance doc names the source snapshot and
the refresh procedure (re-clone / delta-sync) so the snapshot can't silently rot.
