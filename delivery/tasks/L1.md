# L1 — Portable CAS staging on D: (blobs + index + manifest)

## Goal

Raw sessions from every machine stage on the portable drive in a content-addressed, append-only area:
a CAS blob store (identity = hash → de-dup), a human-navigable machine/date index of pointer records,
and a self-describing per-machine manifest so the drive attaches to any machine with no per-machine
config. The single point of truth for un-synthesized raw input. This is the R17 "stage raw now" quick win.

## Context pointers (never inline content)

- Design: architecture/SOLUTION-longview-self-learning.md §4.2 + §5.2 (blobs/index/manifest shapes); steer 2
- Layout root: D:\flywheel-staging\ (blobs\<algo>\<hh>\<hash>, index\<machine>\<date>\<sid>.json, manifests\<machine>.json)
- Emits session_staged KEL events via L0's kel.mjs; gate uses a temp dir fixture (no real D: needed to test)
- Requirements R17–R21; reuse the ${BENNY_HOME}/no-absolute-path rule (R34)

## TDD plan

1. CAS test red: writing the same content twice yields one blob (de-dup by hash).
2. Manifest test: a fixture drive + manifest resumes with no env/config set (plug-and-play).
3. Index test: index record carries machine/process/project/sid + links; browsable by machine/date.
4. Offline test: staging completes with no network and no second machine online.

## Acceptance (BDD — every Scenario must map to an automated test)

```gherkin
Feature: portable, content-addressed, plug-and-play staging
  Scenario: the same session synced twice is stored once
    Given a session blob staged from machine A
    When the identical blob is staged again from machine B
    Then the CAS holds one blob and both index records point to it
  Scenario: the drive attaches to any machine with no config
    Given a staging root with a manifest produced on machine A
    When the pipeline opens it on machine B with no per-machine configuration
    Then it resolves the roots from the manifest and resumes
  Scenario: a staged session is self-describing
    Given a staged session
    When its index record is read
    Then it names the machine, process/agent, project/task context, and sid links into knowledge
  Scenario: staging needs no machine online
    Given no network and no other machine reachable
    When a session is staged
    Then it completes and is admissible to synthesis later
```

## Out of scope

The inbound integrity gate (L2), backup/replication (L3), delta cursors (L4), synthesis. Layout +
de-dup + manifest only.
