# B1 — Coordination server API + SSE

## Goal

The B0 ledger served over HTTP: folded task state, per-task event history, validated append, and
knowledge queries — with every accepted append re-broadcast on the existing EventBus SSE
(`coord.*` topics) so the Bridge and agents see changes live.

## Context pointers

- Plan §3 B1 card (PLAN-local-power-unified-ui.md:213-216); B0 spec: architecture/SPEC-coordination-ledger.md
- Endpoints: GET /api/coord/tasks (folded), GET /api/coord/tasks/:id/events, POST /api/coord/events (validated append), GET /api/coord/knowledge?topic=
- Reuse server/coordination/lib/ledger.mjs (validator + fold + append lock) and the existing EventBus subscribe_all SSE (commits 082b1ae..20d2299) — never a second event system
- Server is the single appender when up (B0 spec: anchors the head hash)
