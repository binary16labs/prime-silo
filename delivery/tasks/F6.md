# F6 — Run diffing

## Goal
Compare two runs of the same manifest: per-node status/duration/attempt deltas, artifact
content-hash changes (text-diff drilldown for text artifacts), judge-score and telemetry deltas.
`benny runs diff <a> <b>` and the Observe view render the SAME comparison (G2 parity discipline).
After Workstream R this becomes the architecture-drift primitive (M2-7).

- Plan §9.5 F6 card (PLAN-local-power-unified-ui.md:513-515)

- CLI and UI parity: same comparison object, two renderers
