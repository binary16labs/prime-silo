# R1 — Evidence dossiers at 16k

## Goal
Per architectural view (Business, Application, Data, Technology), assemble a large evidence
dossier IN CODE (graph queries, deterministic, byte-reproducible) and feed it to the local model
in A1 windows to produce per-view findings — responsibilities, coupling hot-spots, risks, external
contracts — every finding citing node ids.

## Context pointers
- Plan §8 R1 card (PLAN-local-power-unified-ui.md:418-421): the step the 16k window newly enables
- Dossier assembly is deterministic; ONLY findings-prose is model-generated
- Prefill economics (A1): pack dossier windows full, few calls

## TDD plan
1. Red: determinism — fixture dossiers byte-identical from the same graph, twice.
2. Red: poisoned dossier entry (planted fake node id) caught by the citation gate.
3. Implement assembler — green. 4. Findings schema + citation resolution over the fixture.

## Acceptance
```gherkin
Feature: evidence first, prose second
  Scenario: dossiers are reproducible
    Given the fixture graph
    When dossier assembly runs twice
    Then the outputs are byte-identical

  Scenario: fake evidence is caught
    Given a dossier with a planted nonexistent node id
    When validation runs
    Then the citation gate fails naming the fake id

  Scenario: findings are grounded
    Then every generated finding validates against its schema and cites resolvable node ids
```
