# W1 — `work next`: deterministic selector + delivery loop

## Goal
`benny work next` (CLI + MCP, registry-shaped) computes the ready set (deps done, no valid lease,
authority satisfied) and returns exactly ONE item — topological order, then priority, then
lexicographic id. Same state → same item, always. Plus the loop verbs: auto-claim (B-lease),
`work verify` (runs the item's verify command), handoff event, `work blocked <reason>`.
