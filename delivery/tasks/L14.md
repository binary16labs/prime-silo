# L14 — Compound-value triad dashboard

## Goal

Prove the flywheel turns: a dashboard view showing the triad together — held-out eval delta (the honest
anchor) + agent task pass-rate + cost/task — over loop turns, never collapsed into one gameable
composite. Compound value measured end-to-end (sessions↑ → coverage↑ → eval↑ → agent success↑ / cost↓),
not just per-component metrics. R23, R24, R26, R30; steer 6.

## Context pointers (never inline content)

- Design: architecture/SOLUTION-longview-self-learning.md §4.5 (triad) + §4.6; steer 6 (triad, not composite)
- Data source: L5 executions.jsonl (folds eval quality, agent pass-rate, cost per turn); reuse the existing ledger-sourced dashboard style
- Optimization targets are explicit + versioned (R30); a non-improving turn is shown honestly, not hidden (R24)
- Requirements R23, R24, R26, R30

## TDD plan

1. Triad test red: the view renders three separate series (eval delta, pass-rate, cost/task) per turn — no single composite.
2. Honest-negative test: a non-improving turn is displayed (flagged), not omitted.
3. Provenance test: each point traces to the executions.jsonl records it summarizes (auditable).
4. Determinism test: the view is a pure function of the register (same input → same render).
