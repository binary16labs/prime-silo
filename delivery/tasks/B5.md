# B5 — Coordination → execution register (wire the dead mapper)

## Goal

`source_log: "coordination"`. **Nothing calls it** — it is dead code in production. Wire it into a live
projection on the B1 bus, plus a `--rebuild` backfill. Wiring, not new machinery.
