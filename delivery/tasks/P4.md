## Amendment — authoring surface (owner-signed 2026-08-05)

The navigation instrument this contract names (`tool_selection_accuracy` over the agentic SDLC loop)
has **no manifest to run against on today's orchestrator**: the swarm template emits zero G0 node
events, and data-pipeline manifests don't exercise the model's tool selection. `derive_metrics`
needs `node_progress` events carrying `detail.tool` plus a rubric mapping nodes→expected tools, and
nothing produces them (this echoes P6's caveat that only 2 of 8 metrics are derivable). That is an
**instrument gap, not a report defect**.

Owner signed P4 onto the **authoring surface**: a real `pypes model-bench` run of incumbent vs one
candidate, ranked on a declared authoring metric, ledgered. The `navigation` block is recorded
`unavailable` with a reason for both subjects, and `scripts/gates/p4.py` **refuses** a report that
hides the gap behind a silently-empty block. The eight-navigation-field / DAG requirement is waived
under this amendment. **The navigation-instrument gap is carried forward as a new contract**
(an agentic bench manifest + tool rubric wired to the G0 stream) — see the board AUTHORED list.
