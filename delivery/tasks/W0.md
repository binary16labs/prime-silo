# W0 — Work-contract format formalized + full plan-to-backlog conversion

## Goal

Formalize the contract format this delivery/ directory seeds (frontmatter + BDD acceptance), ship its
validator (schema, token budget, dep resolution), and convert EVERY remaining plan phase into
delivery/tasks/ so the board's BACKLOG empties into authored contracts.

## Context pointers

- Plan section 3.5, W0 card (fields; <=~600-token budget; pointers never content; state lives on board/ledger, not in the file)
- Exemplars: delivery/tasks/{Q0,B0,G0,C0,A0}.md + _TEMPLATE.md — formalize THIS format
- Align ids/agents with B0 schema (hence deps: [B0])
- Rule: every authored task updates TRACEABILITY.md + BOARD.md in the same commit

## TDD plan

1. Validator tests: exemplars pass; over-budget fails; unresolved dep fails; nonexistent allowlist path fails; missing Scenario section fails — red.
2. Implement validator (lib + CLI) — green.
3. Convert plan phases in dependency order (split phases into <=budget items where needed).
4. Gate w0.mjs: validate all of delivery/tasks/; dep graph acyclic and consistent with plan section 12; board/traceability cross-check.

## Acceptance

```gherkin
Feature: the entire plan is an executable, validated backlog
  Scenario: every contract validates
    Given all files in delivery/tasks/ excluding _TEMPLATE.md
    When the validator runs
    Then every contract passes schema, token-budget, dep-resolution, and Scenario-presence checks

  Scenario: bloated or vague contracts are rejected
    Given a contract exceeding the token budget or missing acceptance scenarios
    When the validator runs
    Then it exits non-zero naming the contract and the violated rule

  Scenario: nothing is lost between plan and backlog
    Given plan section 12's phase checklist
    When compared against tasks/ plus all board columns
    Then every phase id appears exactly once and the dependency graph is acyclic and matches the plan

  Scenario: traceability is complete
    Then every task id in tasks/ appears in exactly one TRACEABILITY row, and every row's ids exist in tasks/
```
