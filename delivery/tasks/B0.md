# B0 — Coordination ledger spec + validator

## Goal

The shared truth for 4+ agents: append-only tasks.jsonl event schema, knowledge-note format, and a
collision-free lease/claim protocol — spec + validator library + race-proof tests. No server yet (B1).

## Context pointers

- Plan section 3, B0 card (build exactly: event types; ulid/ts/agent/task_id/payload; wx-exclusive leases; 15-min heartbeat)
- Agent registry file coordination/agents.json, seed: claude, antigravity, opencode, benny, human
- Optional run_id field links tasks to G0 streams
- Runtime location: PRIME_SILO_HOME/coordination/ (see HOME-DIRECTORY.md, /api/home)

## TDD plan

1. Schema tests: valid fixtures accepted; each malformed variant (bad ts, unknown agent, missing task_id) rejected — red.
2. Implement JSON schemas + validator lib — green.
3. Lease race: 3 processes race atomic wx create, 20 rounds, exactly one winner each — red then green.
4. Fold tests: event sequences -> task states; expired lease claimable; edited historical line detected.

## Acceptance

```gherkin
Feature: one honest ledger many agents can share
  Scenario: malformed events never enter the ledger
    Given an event missing task_id or with an unregistered agent id
    When the validator processes it
    Then it is rejected with a reason and nothing is appended

  Scenario: concurrent claims yield exactly one winner
    Given 3 processes claiming task T simultaneously via create-exclusive lease files
    Then exactly 1 succeeds and 2 receive already-claimed, in 20 of 20 rounds

  Scenario: expired leases are claimable
    Given a lease whose expires_at is in the past
    When another agent claims task T
    Then the claim succeeds and a task_claimed event records the takeover

  Scenario: ledger is append-only truth
    Given a tasks.jsonl with N events
    Then task states derive solely from folding events
    And an edited historical line is detected by the validator
```
