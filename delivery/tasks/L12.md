# L12 — Human-signed model promotion + rollback

## Goal
Promotion of model N+1 to the served position behind the router requires a human signature — never an
auto-swap on a passing number — and the system supports pinning + rollback (record what N+1 replaced and
how to revert). Extends R23/R36. Builds on the T4 additive router; the served pointer shape is SOLUTION §5.5.

## Context pointers (never inline content)
- Design: architecture/SOLUTION-longview-self-learning.md §4.6 (R39) + §5.5 (served pointer / promotion record)
- Router: runtime/benny/router/tuned_engine.py (T4 — registers house/… candidate, additive, default unchanged)
- Human-signed doctrine: [[owner-working-style]] human-signed-stops; uses L6 served-record
- Requirement R39

## TDD plan
1. Gate test red: a promotion with no human signature is refused (served position unchanged).
2. Signed-promotion test: a promotion carrying a valid human signature swaps the served pointer.
3. Rollback test: after a promotion, revert restores the exact prior served model (pin recorded).
4. No-auto-swap test: a passing metric vector alone, without signature, never changes the served model.

## Acceptance (BDD — every Scenario must map to an automated test)
```gherkin
Feature: the served model changes only by human signature, and is reversible
  Scenario: an unsigned promotion is refused
    Given a candidate model that passes its gate but carries no human signature
    When promotion is attempted
    Then the served position is unchanged
  Scenario: a signed promotion swaps the served model
    Given a candidate with a valid human signature
    When promotion runs
    Then the served pointer names the new model and records the one it replaced
  Scenario: rollback restores the predecessor
    Given a completed promotion
    When rollback is invoked
    Then the exact prior served model is restored
  Scenario: a passing number alone never auto-swaps
    Given a candidate that dominates on metrics but is unsigned
    When the loop completes a turn
    Then the served model is not changed
```
