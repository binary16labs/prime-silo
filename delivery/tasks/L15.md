# L15 — Delivery lifecycle in the OpenLineage DAG

## Goal

Emit OpenLineage RunEvents for the delivery lifecycle and add a coordination source to the
lineage dashboard, so a claim → verify → done cycle is visible as a DAG. Today `lineage.mjs` has zero
coordination references: the delivery workflow does not appear in the DAG at all.

## Context pointers

- Review §1 hop 3 — no coord/tasks.jsonl/delivery references in the dashboard's `lineage.mjs`
- Reuse the RunEvent shape the LONGVIEW pipeline already emits; do not invent a second format
- KR2.2: "every run is one event stream = progress + telemetry + lineage"

## TDD plan

1. Red: a delivery cycle emits START/COMPLETE RunEvents with the task id as the job name.
2. Red: the DAG renders a delivery run alongside pipeline runs, drillable to the contract.
3. Red: a run absent from the ledger never appears in the DAG — no fabricated nodes.
4. Implement the emitter + the dashboard source.
