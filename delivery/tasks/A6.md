# A6 — Sovereignty gradient (no capable local model ≠ no sovereignty)

## Goal
Three user-visible generation tiers — full local, LAN local, frontier-assisted — where only
inference tokens ever leave the machine: knowledge, graphs, lineage, ledger, judge, and sandbox
stay local and are served over MCP regardless of where generation happens.

## Context pointers
- Plan §2 A6 card (PLAN-local-power-unified-ui.md:173-180): tier definitions + mechanics
- Router matrix gains a `fallback` column per capability profile; remote endpoints flagged `remote: true`, opt-in only
- F2 garage capability report is the single source of "what can this machine do"
- §1.6: capability profiles, never model names; manifests change zero

## TDD plan
1. Red: local endpoint disabled + mock remote configured → A2 task completes via fallback with
   correct lineage and cloud attribution.
2. Red: no fallback configured → honest `no_capable_model` refusal, never a hang.
3. Implement fallback routing — green. 4. MCP-path test: generation step served by a session agent using local graph functions.
