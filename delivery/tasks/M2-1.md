# M2-1 — Voice in Studio (dictate in, read aloud out)

## Goal

Voicebox wired conversationally: dictate a question into Studio chat (transcription) and read any
answer or artifact aloud (TTS, voice selectable per C7 profile). Push-to-talk, never
always-listening. A marquee dyslexia feature hiding in an existing service.

## Context pointers

- Plan §9.5 M2-1 row (PLAN-local-power-unified-ui.md:531 — binding design intent)
- Voicebox :17493 already does both directions (source repo binary16/voicebox, POST /generate + transcription)

## TDD plan

1. Red: push-to-talk fixture audio → transcribed text lands in the chat input (never auto-sent).
2. Red: read-aloud on an answer → playable audio via Voicebox, honest failure if service down.
3. Wire both — green. 4. Property: no microphone stream exists outside push-to-talk hold.
