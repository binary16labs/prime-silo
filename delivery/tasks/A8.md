# A8 — Model-routing hygiene + ingest resilience (hotfix-class)

## Goal

Stop the 2026-07-06 failure class permanently: unconfigured default-role calls must never pick a
model by catalog order, one run must never ping-pong two engines on one NPU by accident, and a
failing ingest must fail in minutes and resume where it stopped — not loop 4-hour batches overnight.

## Acceptance

```gherkin
Feature: model routing is deterministic, swap-free, and ingest is resilient
  Scenario: unconfigured default prefers the loaded model
    Given provider catalog lists model B before model A and model A is currently loaded
    When a default-role call resolves its model
    Then it resolves to model A and no model swap is requested

  Scenario: a run never alternates engines by accident
    Given a run whose primary model is A and a workspace with no explicit role mapping
    When any role in that run resolves its model
    Then it resolves to A
    And a role explicitly mapped to B in the workspace manifest still resolves to B

  Scenario: last-resort catalog pick is loud
    Given no loaded model, no run affinity, and no capability match
    When resolution falls through to the catalog
    Then a WARNING containing "roulette" is logged with the chosen model id

  Scenario: ingest fails in minutes, not hours
    Given an ingest model call that produces no response
    When the configured timeout (default 600s) elapses
    Then the call fails with an honest ledger entry naming the model and elapsed time

  Scenario: ingest resumes, never re-ingests
    Given a 10-card ingest killed after 4 cards completed
    When ingest restarts
    Then exactly the 6 unfinished cards are processed and the 4 completed are hash-skipped

  Scenario: a FRESH process resumes correctly (A8.1 — gap found live 2026-07-06)
    Given a prior process died without marking its completed cards in ingested.json
    When a new process starts the model phase
    Then it reconciles against wiki evidence BEFORE computing pending
    And pending contains exactly the genuinely-unfinished cards
```
