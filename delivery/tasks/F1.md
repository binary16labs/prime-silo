# F1 — Global command palette (Ctrl+K)

## Goal
One palette over everything: verbs (from the G2 registry, authority-filtered — human-only verbs
appear as prepared commands), navigation (shell sections, module views), and nouns (documents,
runs, ledger tasks, graph nodes via existing search APIs). Fuzzy match, keyboard-first, recents on
empty query. ADHD rule: anything reachable by clicking must be reachable by typing.
