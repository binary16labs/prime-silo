# A5 — Offline assurance (prove nothing needs the internet)

## Goal

`benny offload preflight --offline` asserts all router endpoints are localhost, model files are
present, and no manifest references a remote URL; the full A2 dev pack passes under a network
audit proving localhost-only sockets. Offline capability becomes checked, not assumed.

## Context pointers

- Plan §2 A5 card (PLAN-local-power-unified-ui.md:169-171)
- Windows technique: psutil socket audit of the running processes (no firewall dependency)
- router.matrix.json is the endpoint source of truth; §1.6 zero-phone-home NFR

## TDD plan

1. Red: preflight against a fixture matrix containing one remote URL → named refusal.
2. Red: preflight with a missing model file → named refusal.
3. Implement preflight — green. 4. Gate runs the A2 pack under the psutil socket audit.

## Acceptance

```gherkin
Feature: offline execution is proven, not presumed
  Scenario: preflight catches remote references
    Given a router matrix entry with a non-localhost endpoint
    When preflight --offline runs
    Then it exits non-zero naming the offending entry

  Scenario: the dev pack runs with no external sockets
    Given the full A2 pack executing against local lemonade
    When the socket audit runs alongside
    Then every opened socket is loopback and the audit log is attached to the gate output
```
