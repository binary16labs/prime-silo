# L6 — Authorship provenance + record-served tagging (capture-time)

## Goal
Capture authorship provenance (human / frontier-model / house-model) on every staged session and
execution record at capture time, and record which model is served behind the router and what it
replaced. This is the wave-1 half of R38 (tagging) and R39 (record-served) — the fraction-cap/verifier
gate (R38) and the promotion gate (R39) activate in wave 3 (L11/L12). Makes §8 dogfooding auditable
from the first house-authored session.

## Context pointers (never inline content)
- Design: architecture/SOLUTION-longview-self-learning.md §4.6 (R38 tag / R39 record) + §5.5 (served pointer shape) + §9.5
- Authorship field on KEL events (L0) and register records (L5); served pointer per SOLUTION §5.5
- Requirements R38 (tagging only), R39 (recording only)

## TDD plan
1. Tag test red: a staged session and its execution record carry authorship in {human, frontier, house}.
2. Untagged-reject test: a record missing authorship is rejected by the gate.
3. Served-pointer test: promoting a served model writes a pointer naming the model and what it replaced.
