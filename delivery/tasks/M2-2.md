# M2-2 — Feedback → judge calibration loop

## Goal

Thumbs-up/down on every offload artifact appends to a per-task-type golden set; the judge gate
recalibrates against the growing set on an F3 schedule. Quality compounds instead of being a
one-time A0 calibration.

## Context pointers

- Plan §9.5 M2-2 row (PLAN-local-power-unified-ui.md:532 — binding design intent)
- A0's JUDGE-CALIBRATION.md pattern is the seed; feedback extends the known-good/known-bad sets
- Recalibration is a scheduled workflow (F3) — governed, ledgered, no side-door

## TDD plan

1. Red: a thumbs-down on a fixture artifact appends it to the task type's known-bad set with provenance.
2. Red: scheduled recalibration folds the grown set and updates the judge threshold record.
3. Implement feedback capture + recalibration manifest — green. 4. Judge verdict drift test: a previously-passing bad output now fails.
