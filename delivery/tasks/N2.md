# N2 — estate console page + live API

## Goal
`server/pages/estate.html` — the governance console — reading the estate model over an **additive** API
(`estate_api.mjs`, mounted in `app.js` ahead of the generic handler like B1) and pushed live via the B1 SSE
bus. It **composes existing primitives** (does not reinvent): the `navi-key` arc/dot-matrix hub + satellite,
the `lineage-timeline` drill-down, and the anime.js Dial. Motion-is-meaning (C0): every animation is driven
by a real estate/SSE event, never a timer; the final state is in the markup so the page is complete with JS
disabled; theme-aware; reduced-motion safe. Traces O2.KR2.2.

   (fall-through preserved). Write the test first, watch fail.

   with no JS (final state present); a gate assert confirms the nodes exist in source.
