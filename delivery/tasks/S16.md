## What is wrong now

1. **The sentence the owner reads first is asserted nowhere.** Hard-coding `reportingLine()` to
   "3 nodes reporting", making it ignore `allStale` so a wholly silent estate reads as reporting, or
   forcing every card's badge to read LIVE — each ships GREEN at 55/55. The file's own comments cite
   "a header still reading 14 nodes reporting" twice as what made earlier defects damning, so the
   judgement is tested one layer below where it is read.
2. **The clipping comment is false.** It says clipping is the only way an approved declaration puts
   content out of reach. `.em__card { position: absolute }` — one approved declaration, no clipping
   property — stacks every card at one point with only the last readable, measured on a fourteen-node
   fold under a header still reading "14 nodes reporting". I wrote that sentence while closing the
   finding about at-rules, which is the same mistake one round later.
