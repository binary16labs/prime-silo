# S28 — one budget rule, and it is the blocking one that is wrong

## Goal

S27 made the **reporting** rule honest and left the **blocking** one divergent.
`sandbox_provision.mjs` `checkBudget` sums added **and deleted**, excludes only `tests/` and
lockfiles, and is the rule that actually refuses work through `workVerify`'s `over-budget`. Under
the pinned convention replacing 50 lines costs 50; under `checkBudget` it costs 100. S27's stated
purpose was that author and verifier derive one number from one rule, and it shipped a second.
Both of its verifiers named this as the more important of the two, because this one refuses.

## Context pointers (never inline content)

- `server/coordination/work-schema/validate.mjs`: `readBudget`, `gatherBudgetRows`,
  `generatedOutputs`, `NEVER_TOUCH`
- `server/coordination/lib/sandbox_provision.mjs`: `checkBudget`, and `workVerify`'s `over-budget`
- `architecture/SPEC-work-contracts.md`: the counting convention pinned 2026-10-23
- `delivery/board/LOG.md`, the three S27 verifier lines: the four coverage gaps and two LOWs below

## What to close

1. **One rule.** `checkBudget` derives its figure from `readBudget` under the pinned convention —
   added lines only, the contract file, `tests/`, `delivery/board/`, generated output and the
   never-touch roots excluded. A refusal and a reading must never disagree about the same branch.
2. **The ordering gap, which is the vacuous-check class for the third time.** Sorting the counted
   rows by **path** instead of size still passes, because the fixture's paths happen to sort in
   size order. Adding a row killed the instance and left the class. Every wrong ordering must
   produce a different answer.
3. **Values, not shapes.** The counted rows are asserted by path and never by figure — doubling
   every one survives, printing rows summing to 586 under a stated total of 293. The per-root
   skipped-file count is asserted for shape and never for value, though that count is the whole
   reason a skipped tree is named rather than omitted.
4. **Prefix, not substring.** `NEVER_TOUCH` carries the three-character `run`, and this repo has a
   real top-level `runtime/` of 711 tracked files. One character — prefix match to `includes` —
   silently drops it, in the under-counting direction. The code is right; nothing defends it.
5. **The two LOWs.** `generatedOutputs` matches one `const OUT = path.resolve(repo, arg("out", …))`
   idiom and silently skips a build script that declares its output directory any other way;
   `generatedCache` is a module-level `Map` that is never invalidated, and `validate.mjs` lives
   under `server/`.

## TDD plan

For 1, one branch fixture measured by both paths, asserting the same figure, plus a replace-only
diff where the old rule said 100 and the convention says 50. For 2, paths whose alphabetical order
**contradicts** their size order, so no ordering but the right one passes. For 3, assert the figures
and the per-root count by value. For 4, an untracked file under `runtime/` that must be counted. For
5, a fixture build script with a different `OUT` idiom that is either read or reported, never
silently skipped.
