# F2 — Model garage (+ live compute telemetry + Test Drive)

## Goal

Local-model ops without arcana: installed-model inventory with health/loaded/ctx state, one-click
load with correct recipe_options (the 16k lesson codified), wedge detection surfaced from the A0
watchdog with SUPERVISED one-click restart (never automatic), a stored throughput benchmark per
compute target (NPU/GPU/CPU) with power figures feeding F5 — and live utilization so nobody opens
Task Manager again.
