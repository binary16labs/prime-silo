# L11 — Model-collapse guard (verifier gate + house-fraction cap)

## Goal

The loop trains on validated method, never raw self-output. A house-authored session becomes a training
row only after passing a verifier gate (frozen rubric or frontier sign-off), and house-origin rows are
fraction-capped per training turn. Without this, sessions→train→model→sessions drifts into
distillation-of-self and collapses. Extends R24/R25; this is the guard that makes §8 dogfooding safe. R38.

## Context pointers (never inline content)

- Design: architecture/SOLUTION-longview-self-learning.md §4.6 (R38 guard) + §8 (dogfood delivery doctrine)
- Extends the leak-gate wiring already in scripts/train/build_dataset.mjs (house-trainer skill); uses L6 authorship tags
- Verifier gate = frozen rubric (scripts/train/eval/rubric.md) or a recorded frontier sign-off event
- Requirement R38 (the fraction-cap + verifier-gate half; tagging is L6)

## TDD plan

1. Verifier-gate test red: a house-authored session with no verifier pass is excluded from training rows.
2. Pass-through test: a house session with a recorded verifier pass is admitted.
3. Fraction-cap test: house-origin rows exceeding the configured cap for a turn are down-sampled to the cap.
4. Provenance test: human/frontier rows are never capped; only house-origin is bounded.
