# F3 — Watched folders + scheduler

## Goal
Two triggers for catalog types with zero side-door execution: watched folders
(`PRIME_SILO_HOME/inbox/<type>/` — a landing file instantiates the mapped type with itself as
source) and a scheduler (`PRIME_SILO_HOME/schedules.json`, cron-like). Both produce a normal
ledger task + G0 run. Only human-signed catalog types are schedulable.

## Context pointers
- Plan §9.5 F3 card (PLAN-local-power-unified-ui.md:500-502)
- Determinism boundary: agents may DRAFT schedule entries; a human enables them (ADR-001)
- Classic use: drop a PDF → auto-ingest; nightly LONGVIEW delta; release-time demo re-capture
- Battery rule from F2: discretionary scheduled runs defer to AC power
