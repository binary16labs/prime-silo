# C1 — Adaptive layout contract (kills squashed graphs)

## Goal

Panes genuinely fill the viewport at every resolution: flex/grid chain with min-height/min-width 0
at every level, a shared PaneContract helper (ResizeObserver → debounced resize(w,h) into every
visualization widget), user-resizable splits remembered in localStorage, container queries for
pane-level responsiveness.

## Context pointers

- Plan §5 C1 card (PLAN-local-power-unified-ui.md:316-323); widget wrappers to touch: force_graph_2d, kg3d, dag, codegraph, three_renderer
- Hard rule: no widget reads window.innerWidth or hardcodes canvas dimensions
- §1.6 performance budget: graph views must survive the 200k-node code-graph and 30k-concept fixtures
