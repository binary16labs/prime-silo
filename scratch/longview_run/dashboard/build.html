Pace by class — why a duration is what it is

Arc-carrying sections retrieve more (topK 14 vs 10) and run an extra critique → revise pass, so they cost ~4× a plain section. A single mean over both classes mis-projects whichever class dominates the remainder, so the ETA is computed per class and each mean shows its sample size.
