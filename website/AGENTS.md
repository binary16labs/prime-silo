# Prime-Silo Marketing Website (`website/`)

## Scope & Ownership

This document defines the runtime, design, and build contract for the Prime-Silo marketing website hosted in `website/`.

## Owned Files & Surfaces

- `website/content.json`: Single source of truth for all copy, section ordering, features, FAQ, roadmap, SEO metadata, JSON-LD, interactive Silo layers (`interactiveSilo`), Live Terminal workflows (`interactiveTerminal`), and honest calculator defaults.
- `website/template.html`: HTML5 skeleton containing semantic section placeholders (`{{siloSection}}`, `{{terminalSection}}`) and inline Benny mascot symbols (`#benny-symbol`).
- `website/styles.css`: Evolved earth-tone design tokens (`--alabaster`, `--moss`, `--rust`, `--sage`, `--taupe`), sticky-chapter stages, interactive isometric Silo slabs (`.silo-slab`), interactive Terminal mockup (`.terminal-mockup`), and Neuro-Assist accessibility dock styling.
- `website/app.js`: ES module orchestrating scroll-driven explode animations (`anime.js v4`), Benny mascot micro-animations, Interactive Sovereign Stack Silo explode/compress choreography, Live Agent Terminal log streaming & kinetic graph canvas, Neuro-Assist accessibility controls, and interactive honest cost calculator.
- `website/build.mjs`: Zero-dependency Node.js script that compiles `content.json` + `template.html` into `index.html`, `sitemap.xml`, and `robots.txt`.
- `website/vendor/anime.esm.min.js`: Vendored ES module bundle of anime.js v4.

## Stable Contracts & Enforcement

1. **Never Edit `index.html` Directly**:
   - `index.html` is generated by `node website/build.mjs`. Direct edits are prohibited and will be overwritten.
2. **Honesty & Validation**:
   - The build script strictly rejects any legacy invalidated cost claims (`98%`, `$2,363`, `$34`, `token tax`) and unresolved bracket copy placeholders.
   - All interactive calculator outputs must explicitly state their underlying formulas and assumptions.
3. **Zero-Dependency Build**:
   - `build.mjs` must run on standard Node.js without requiring external `npm install` packages.
4. **Local-First & Relative Assets**:
   - All asset paths must be relative (`./styles.css`, `./og-image.png`, etc.). Root-absolute paths (`/prime-silo/`) are rejected by build lints.

## Changes Requiring Documentation Updates

- Changes to section ordering or new sections in `content.json` and `template.html`.
- Additions or modifications to safety lints in `build.mjs`.
