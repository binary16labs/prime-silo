The Third Graph of the Cognitive Mesh

Memo-Ray: The Memory Graph

You should never have to be the institutional memory for your AI agents. Memo-Ray reads session logs, distils them into a portable atomic entity database, and renders them as an organic, explorable lineage graph.

Storage

Portable Entity Object Architecture

Discarding heavy DBs for an ultra-portable file system architecture. Every session, thought, tool call, and artifact is a distinct JSON file under server/data/entities/. A central data_model_abstract.md defines the strict ontology for agents to natively understand the ecosystem.

Engine

Delta Sync Engine

Dynamically reads local Claude Code and Antigravity directory logs. Checks "Last Modified" timestamps and only parses new/updated files to ensure lightning-fast UI loads. Keep your data on your local machine (localhost-only CORS).

View

Comprehensive Governance

Maps Claude web chats, Claude Code sessions, Co-work caches, and Antigravity transcripts all in one unified interface. Project artifacts (PRDs, plans) are directly linked as distinct structural nodes within the conversation trees.

UI/UX

Biological Graph Visualization

Built ADHD/dyslexia-first: spatial maps over walls of JSON. Steps are cells; D3 Convex Hulls group threads into translucent organs. Clicking a node progressively "sprouts" its lineage. Visual weighting shows rank/importance via cell size using earthy palettes.

Integration

Cognitive Mesh Enrichment

The file-interaction timeline records which sessions touched which files. A CORRELATES_WITH overlay links the memory graph to Prime-Silo's code graph, answering "show me every conversation that shaped this module."

Controls

Unified Interface & Filters

The left sidebar lists sessions and a Files explorer. The collapsible right sidebar houses powerful filters to dynamically toggle visibility of User Inputs, Tool Calls, Thoughts, Artifacts, and Co-work. Works seamlessly across Windows, macOS, and Linux.
