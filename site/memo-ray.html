Ecosystem Integration

Seamless by design

The Memo-Ray MCP operates as an agnostic layer over your agents' native logs.

Currently Supported

The current solution works flawlessly out-of-the-box with:

1. Claude Desktop & Claude Code: Dynamically reads local `.claude` directories.
2. Antigravity Gemini: Hooks directly into the `~/.gemini/antigravity/brain` roots.

Future Onboarding

Because the delta-sync engine relies on an open Data Model Abstract, other AI agents and desktop solutions will be seamlessly onboarded. The architecture is explicitly designed to map any valid JSON log stream into the universal Memory Graph.

Operating manual

Install the MCP Server

Zero to operator in three steps. Connect the graph to your agent.

Clone the Prime-Silo / Memo-Ray repository and install the server dependencies. It runs purely on Node.js. 

git clone https://github.com/binary16labs/prime-silo.git
cd prime-silo/memo-ray/mcp-server
npm install

Add the Memo-Ray server to your Claude Desktop MCP configuration file (claude_desktop_config.json). Make sure to replace the path with your absolute path. 

{
  "mcpServers": {
    "memoray": {
      "command": "node",
      "args": [
        "C:/Users/YourName/prime-silo/memo-ray/mcp-server/index.js"
      ]
    }
  }
}

Restart Claude Desktop to apply the changes. The tools will now be available in the attachment menu.

Antigravity automatically discovers MCP servers configured in its plugin directories, or you can register it globally via your mcp.json or Antigravity's settings portal. 

{
  "mcpServers": {
    "memoray-mcp": {
      "command": "node",
      "args": [
        "C:/Users/YourName/prime-silo/memo-ray/mcp-server/index.js"
      ]
    }
  }
}
